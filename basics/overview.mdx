## What is Unify?

Unify makes the leap from standalone AI agents to fully fledged virtual colleagues.

These are not personal assistants you prompt and wait. These are colleagues — with their own name, personality, computer, and an ever-growing memory and skill set. You onboard them like any new hire: share your screen, walk them through your tools, hop on a call. They learn how your team works, ask follow-up questions, and improve over time.

## How it works

Your virtual colleague can simultaneously use their own computer, talk to you via voice, follow your live guided screenshare instructions, and consolidate new skills on-the-fly — just like a person would. They can be interrupted and redirected at any point.

This is powered by a fundamentally different architecture:

- **Steerable handles** — every operation returns a live handle you can pause, resume, interject into, or stop at any depth
- **CodeAct** — the actor writes Python programs over typed primitives, not flat JSON tool calls
- **Dual-brain voice** — a slow deliberation brain + a fast real-time voice agent, communicating over IPC
- **Continuous memory** — contacts, knowledge, tasks, and relationships consolidated into structured, queryable tables

## Running locally

<Note>
  **Coming soon.** We're actively decoupling Unity for full standalone local deployment. See the [roadmap](https://github.com/unifyai/unity#roadmap) for progress.
</Note>

**What works today:** You can clone the repo, run the full test suite, and explore the architecture. Tests exercise the real system — steerable handles, CodeAct, manager composition, nested tool loops — against simulated backends with cached LLM responses.

```bash
git clone https://github.com/unifyai/unity.git
cd unity
pip install uv && uv sync --all-groups
source .venv/bin/activate
cp .env.example .env    # Add your OPENAI_API_KEY / ANTHROPIC_API_KEY
tests/parallel_run.sh tests/
```

**Full local deployment (coming soon):** We're working toward a single `docker compose up` that runs the complete system on your machine — brain, local persistence (Orchestra + PostgreSQL), communication channels, and web console. The main work is replacing GCP-specific infrastructure (Pub/Sub, Cloud Functions, GCS) with portable alternatives. The brain itself is already infrastructure-agnostic.

See the full [Running Locally](https://github.com/unifyai/unity#running-locally) section in the repo README for details on what's being decoupled.
