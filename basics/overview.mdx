## What is Unity?

Unity is the open-source brain of an AI assistant. It implements the assistant's intelligence through a distributed architecture of specialized **state managers** (ContactManager, TaskScheduler, KnowledgeManager, etc.), each orchestrated by a central **Actor** through code-first plans.

## What makes it different

Most agent frameworks work like this: one LLM, one loop, one tool call at a time. If you want to interrupt, you cancel and start over.

Unity works differently. Every operation runs inside its own async LLM tool loop and returns a [**steerable handle**](/architecture/steerable-handles). These handles compose: the ConversationManager steers the Actor, the Actor steers the managers, and the user steers the ConversationManager. Steering propagates through the full depth.

This means the assistant can:
- Run several things at once and let you steer each one independently
- Accept corrections mid-task without restarting
- Pause work, handle something urgent, and resume where it left off
- Hold a real-time voice conversation while doing background work

## Architecture at a glance

```
ConversationManager (dual-brain orchestration)
    │
    │   Slow Brain ◄── IPC ──► Fast Brain (real-time voice)
    │
    ▼
CodeActActor (generates Python plans, calls primitives.* APIs)
    │
    ▼
State Managers (each runs its own async LLM tool loop)
    ├── ContactManager        — people and relationships
    ├── KnowledgeManager      — domain facts
    ├── TaskScheduler         — durable tasks and execution
    ├── TranscriptManager     — conversation history
    ├── GuidanceManager       — procedures and SOPs
    ├── FileManager           — file parsing
    ├── WebSearcher           — web research
    ├── SecretManager         — encrypted secrets
    └── ...more
    │
    ├── EventBus              — typed pub/sub backbone
    └── MemoryManager         — offline knowledge consolidation
```
