---
title: "Poll for a message response"
api: 'GET /v0/messages/{message_id}'
---
Check the status of a previously sent message. Returns 'processing' while the assistant is working, and 'completed' (with an optional response) once done.

#### Authorizations

<ParamField header="Authorization" type="string" required="true">
  Bearer authentication header of the form `Bearer <token>`, where `<token>` is your auth token.
</ParamField>

#### Path Parameters

<ParamField query="message_id" type="string" required="true">
The unique message ID returned by POST /messages.
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.unify.ai/v0/messages/msg_abc123' \
  --header "Authorization: Bearer $UNIFY_KEY"
```

```python Python
import requests

url = "https://api.unify.ai/v0/messages/msg_abc123"

headers = {"Authorization": "Bearer <token>"}

response = requests.request("GET", url, headers=headers)

print(response.text)
```
