---
title: "Set Member Spending Limit"
api: 'PUT /v0/organizations/{organization_id}/members/{member_user_id}/spending-limit'
---
Set the monthly spending limit for a member within an organization.

This limit controls how much the member can spend when using the org's API key.
It is separate from the user's personal spending limit (which applies to their
personal API key).

The member limit cannot exceed the organization's limit.
When the limit is lowered, assistant limits owned by this member that exceed
the new limit will be automatically capped.

#### Authorizations

<ParamField header="Authorization" type="string" required="true">
  Bearer authentication header of the form `Bearer <token>`, where `<token>` is your auth token.
</ParamField>

#### Path Parameters

<ParamField query="organization_id" type="integer" required="true">

</ParamField>

<ParamField query="member_user_id" type="string" required="true">

</ParamField>

#### Body

<ParamField body="monthly_spending_cap" type="number | null" required="true">
Monthly spending limit in dollars for this member. Set to null for no limit.
</ParamField>

<RequestExample>

```bash cURL
curl --request PUT \
  --url 'https://api.unify.ai/v0/organizations/<organization_id>/members/<member_user_id>/spending-limit' \
  --header "Authorization: Bearer $UNIFY_KEY"
  --header 'Content-Type: application/json' \
  --data '{
    "monthly_spending_cap": 100.0
}'
```

```python Python
import requests

url = "https://api.unify.ai/v0/organizations/<organization_id>/members/<member_user_id>/spending-limit"

headers = {"Authorization": "Bearer <token>"}

json_input = {"monthly_spending_cap": 100.0}

response = requests.request("PUT", url, json=json_input, headers=headers)

print(response.text)
```
