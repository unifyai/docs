---
title: "Set Org Spending Limit"
api: 'PUT /v0/organizations/{organization_id}/spending-limit'
---
Set the monthly spending limit for an organization.

When the limit is lowered, member and assistant limits that exceed the new org limit
will be automatically capped to the org limit (eager cascade).

Setting to null removes the limit (no cap for members/assistants from this org).

#### Authorizations

<ParamField header="Authorization" type="string" required="true">
  Bearer authentication header of the form `Bearer <token>`, where `<token>` is your auth token.
</ParamField>

#### Path Parameters

<ParamField query="organization_id" type="integer" required="true">

</ParamField>

#### Body

<ParamField body="monthly_spending_cap" type="number | null" required="true">
Monthly spending limit in dollars. Set to null to remove the limit.
</ParamField>

<RequestExample>

```bash cURL
curl --request PUT \
  --url 'https://api.unify.ai/v0/organizations/<organization_id>/spending-limit' \
  --header "Authorization: Bearer $UNIFY_KEY"
  --header 'Content-Type: application/json' \
  --data '{
    "monthly_spending_cap": 500.0
}'
```

```python Python
import requests

url = "https://api.unify.ai/v0/organizations/<organization_id>/spending-limit"

headers = {"Authorization": "Bearer <token>"}

json_input = {"monthly_spending_cap": 500.0}

response = requests.request("PUT", url, json=json_input, headers=headers)

print(response.text)
```
