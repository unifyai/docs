---
title: "Update Org Mfa Settings"
api: 'PUT /v0/organizations/{organization_id}/mfa-settings'
---
Update MFA enforcement settings for an organization.

Requires org:write permission (Owner, Admin roles).

#### Authorizations

<ParamField header="Authorization" type="string" required="true">
  Bearer authentication header of the form `Bearer <token>`, where `<token>` is your auth token.
</ParamField>

#### Path Parameters

<ParamField query="organization_id" type="integer" required="true">

</ParamField>

#### Body

<ParamField body="require_mfa" type="boolean" required="true">
Whether to require MFA for all members.
</ParamField>

<RequestExample>

```bash cURL
curl --request PUT \
  --url 'https://api.unify.ai/v0/organizations/<organization_id>/mfa-settings' \
  --header "Authorization: Bearer $UNIFY_KEY"
  --header 'Content-Type: application/json' \
  --data '{}'
```

