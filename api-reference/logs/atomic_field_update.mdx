---
title: "Atomic Field Update"
api: 'PATCH /v0/logs/{log_id}/fields/{field_name}/atomic'
---
Apply an atomic operation to a numeric field in a log entry.

This endpoint performs race-safe atomic updates directly in PostgreSQL,
ensuring correct results even under high concurrent load.

Supported operations:
- `+N`: Add N to the current value
- `-N`: Subtract N from the current value
- `*N`: Multiply the current value by N
- `/N`: Divide the current value by N

If the field doesn't exist or is NULL, it is treated as 0 before the operation.

#### Authorizations

<ParamField header="Authorization" type="string" required="true">
  Bearer authentication header of the form `Bearer <token>`, where `<token>` is your auth token.
</ParamField>

#### Path Parameters

<ParamField query="log_id" type="integer" required="true">
The ID of the log to update
</ParamField>

<ParamField query="field_name" type="string" required="true">
The name of the field to update atomically
</ParamField>

#### Body

<ParamField body="operation" type="string" required="true">
Atomic operation to apply. Supported formats: +N, -N, *N, /N where N is a number.
</ParamField>

<ParamField body="field" type="string | null" >
(Upsert mode) Name of the numeric field to update atomically.
</ParamField>

<ParamField body="project" type="string | null" >
(Upsert mode) Name of the project.
</ParamField>

<ParamField body="context" type="string | null" >
(Upsert mode) Context path for the log.
</ParamField>

<ParamField body="unique_keys" type="object | null" >
(Upsert mode) Unique key configuration for the context. Maps key names to types (str, int, float).
</ParamField>

<ParamField body="initial_data" type="object | null" >
(Upsert mode) Data to use when creating a new log entry. Must include all unique key values.
</ParamField>

<ParamField body="add_to_all_context" type="boolean"  default="false">
(Upsert mode) If true, also adds the log to the 'All/*' archive context.
</ParamField>

<RequestExample>

```bash cURL
curl --request PATCH \
  --url 'https://api.unify.ai/v0/logs/<log_id>/fields/<field_name>/atomic' \
  --header "Authorization: Bearer $UNIFY_KEY"
  --header 'Content-Type: application/json' \
  --data '{
    "operation": "+1",
    "field": "cumulative_spend",
    "project": "Assistants",
    "context": "42/7/Spending/Monthly",
    "unique_keys": {
        "_assistant_id": "str",
        "month": "str"
    },
    "initial_data": {
        "_assistant_id": "123",
        "_org_id": 456,
        "month": "2026-01"
    }
}'
```

```python Python
import requests

url = "https://api.unify.ai/v0/logs/<log_id>/fields/<field_name>/atomic"

headers = {"Authorization": "Bearer <token>"}
```
