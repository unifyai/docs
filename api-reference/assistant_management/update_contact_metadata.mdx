---
title: "Update contact metadata"
api: 'PUT /v0/assistant/{assistant_id}/contact'
---
Updates non-provisioned fields (user_value, metadata) on an existing contact. Changing the actual provisioned resource requires delete + create.

#### Authorizations

<ParamField header="Authorization" type="string" required="true">
  Bearer authentication header of the form `Bearer <token>`, where `<token>` is your auth token.
</ParamField>

#### Path Parameters

<ParamField query="assistant_id" type="integer" required="true">

</ParamField>

#### Body

<ParamField body="contact_type" type="string" required="true">
The type of contact to update.
</ParamField>

<ParamField body="user_value" type="string | null" >
Updated user-side value (e.g., personal phone for forwarding).
</ParamField>

<ParamField body="metadata" type="object | null" >
Updated type-specific metadata (merged with existing).
</ParamField>

<RequestExample>

```bash cURL
curl --request PUT \
  --url 'https://api.unify.ai/v0/assistant/<assistant_id>/contact' \
  --header "Authorization: Bearer $UNIFY_KEY"
  --header 'Content-Type: application/json' \
  --data '{
    "contact_type": "phone",
    "user_value": "+15559876543"
}'
```

```python Python
import requests

url = "https://api.unify.ai/v0/assistant/<assistant_id>/contact"

headers = {"Authorization": "Bearer <token>"}

json_input = {"contact_type": "phone", "user_value": "+15559876543"}

response = requests.request("PUT", url, json=json_input, headers=headers)

print(response.text)
```
